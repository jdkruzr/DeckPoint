The first DeckPoint release: a keyboard-first e-reader for the LilyGo T-Deck Pro, built on
[CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) and inspired by
[CrossInk](https://github.com/uxjulia/CrossInk).

## Highlights

- **Read with the keyboard**: vim-style keys (`j`/`k`, counts, `gg`/`G`, `]]`/`[[`, marks,
  `/` search), a `:` command line, and `?` help on every screen.
- **Highlights and notes**: select with `v` + word labels or a long-press, write notes in a
  bottom sheet while the page stays visible, browse them with `:notes`.
- **Export**: `:export` writes Markdown (Obsidian-friendly) and a `My Clippings.txt`.
- **KOReader-compatible highlight sync** over WebDAV (Nextcloud and friends) in
  AnnotationSync.koplugin's format, with KOReader-exact positions, including highlights that
  span chapters. Built not to lose your notes to a device with a wrong clock.
- **KOSync** reading-progress sync, done together with highlights by `:sync`.
- **Dictionary lookup** by label: press `d`, then type the label shown on the word.
- Touch support, a bottom key legend, and themes tuned for the 240x320 screen.

## Installing on a T-Deck Pro

This replaces the factory firmware (LilyGo demo / Meshtastic). Your SD card is not touched.

**In the browser (Chrome/Edge):** open <https://espressif.github.io/esptool-js/>, **Connect**
to the device, set Flash Address `0x0`, choose `deckpoint-tdeckpro-full.bin`, **Program**, then
press the lower side button to restart.

**Command line:**

```bash
pip install esptool
esptool --chip esp32s3 write-flash 0x0 deckpoint-tdeckpro-full.bin
```

No serial port? Hold the **upper** side button, tap the **lower** one, release the upper
one, and try again (and try a different cable: many USB-C cables are charge-only).

Then put EPUBs on the SD card, press `?` anywhere, and see
[INSTALL.md](https://github.com/jdkruzr/DeckPoint/blob/deckpoint/docs/deckpoint/INSTALL.md)
for the dictionary, Wi-Fi, time zone and sync setup.

## Known rough edges

- Every device syncing highlights must use the same time zone (KOReader's timestamps carry
  none). DeckPoint warns while its own time zone is unset.
- Highlight ends snap to whole words ("prisoners…we" includes "we").
- During a long `/` search the page shows without gray anti-aliasing until it finishes.
